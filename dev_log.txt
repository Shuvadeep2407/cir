#### C-UAS Application Notes
- **Detection radius:** 260 m (omnidirectional, 360° coverage) — each CTLRR-220PRO covers a ±60° sector; 3 units at 120° spacing achieve full-circle coverage with ~60° overlap between adjacent sectors.
- **Radar subsystem power input:** 24 VDC — the system power bus supplies 24 VDC to each radar mounting point; an onboard regulator on the radar interface board steps 24 VDC down to the module's 9–16 V DC operating range.
- **Command link:** LoRa wireless — each radar module connects via CAN/CAN FD to the local gateway (STM32WL or STM32F103), which relays track data to the AI workstation / operator console over a LoRa wireless telemetry link.

### Acoustic Array Details
The acoustic array is recorded as a custom 8-channel passive direction-finding subsystem based on INMP441-compatible omnidirectional microphone modules.

#### Product Introduction
- **Module:** INMP441-compatible omnidirectional microphone module
- **Array:** 8 microphones, 8-direction coverage
- **Reflector:** 200 mm parabolic reflector disk
- **Processing Circuit:** STM32F411 custom circuit
- **Purpose:** Passive acoustic cueing and bearing estimation for drone detection
- **Status:** Detection range and beamforming performance still need field validation

### System Integration Notes
- Each mmWave radar module should connect to the local gateway over CAN/CAN FD.
- Preferred gateway options are STM32WL or STM32F103, with LoRa used for telemetry backhaul when needed.
- Radar track data can then be forwarded from the gateway to the AI workstation and operator console for logging and display.
- Acoustic array output should be processed by the STM32F411 custom circuit and forwarded to the AI workstation and operator console for display and logging.
